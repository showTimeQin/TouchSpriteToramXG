# TouchSpriteToramXG

《托兰异世录》（Toram Online）手游的**触动精灵（TouchSprite）自动挂机脚本 —— 小骨脚本**，作者 Kami桑。自动打小骨、循环挂机，支持多版本模式和传送点配置。

## 功能

- 自动刷「小骨」怪，多协程循环挂机
- 版本模式：完全版 / 不写日志版 / 无监控版 / 低配版 / 无日志破压制 / 买机票
- 传送点位置可选（第一 / 第二 / 第三个）
- 统计出售次数、运行时间，自动写日志

## 环境

- 触动精灵（TouchSprite）安卓端，脚本基于其 Lua API（`init`、`touchDown/mSleep`、`showUI`、`thread` 协程等）
- 分辨率固定 **720 × 1280**（脚本内 `setScreenScale(true, 720, 1280)`，其他分辨率会提示不支持）
- 启动密码：`1024`（见 `main.lua`）

## 文件

| 文件 | 说明 |
| --- | --- |
| `main.lua` | 主脚本：UI 配置、密码校验、启动各协程 |
| `720p.lua` | 720p 分辨率下的坐标 / 操作封装 |
| `CONSTANT.lua` | 常量：时间、金额、传送点坐标等 |
| `Tools.lua` | 工具函数（计时等） |
| `TSLib.lua` | 触动精灵库文件（二进制） |
| `ToramXG.tsproj` | 触动精灵工程文件 |

## 使用

将整个目录导入触动精灵，加载 `ToramXG.tsproj`，在脚本界面选择版本模式与传送点、输入密码后启动。脚本内子协程会随主脚本停止而自动停止。
